# Curriculum Overview

The curriculum contains 31 numbered modules that cover the 32 technical areas
from the original 36-point preparation plan. The remaining points define the
master map, scenario framework, case studies, roadmap, and mock-interview
workflow.

Use the [current learning path](../index.md#current-learning-path) for the canonical
order of released modules. Use the [study roadmap](../roadmap.md) for the study
sequence. All 31 numbered modules are initial releases; use the
[master competency map](../master-competency-map.md) for original-plan traceability
and the [v1 readiness report](../release-readiness.md) for validation evidence.
