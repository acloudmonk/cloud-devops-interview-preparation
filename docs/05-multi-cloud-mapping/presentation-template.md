# Ten-Minute Cross-Cloud Architecture Review

[← Advanced drills](scenario-drills.md) · [Next: Rapid fire →](rapid-fire.md)

- **0:00–1:00:** business drivers, journeys, data, SLOs, constraints, assumptions.
- **1:00–2:30:** placement options, weighted criteria, selected portfolio pattern.
- **2:30–4:00:** hierarchy, landing zones, governance, identity, keys, evidence.
- **4:00–6:00:** network, runtime, data, integration, and semantic gaps.
- **6:00–7:30:** provider/region loss, data authority, failover, reconciliation.
- **7:30–8:30:** delivery, observability, operations, support, ownership.
- **8:30–10:00:** total cost, quota/capacity, risks, roadmap, proof, exit triggers.

Close with where multicloud creates measurable value and where standardization or
consolidation avoids needless complexity.
