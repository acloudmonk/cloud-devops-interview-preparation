## Suggested review loop

1. Pick one real or invented portfolio and define outcomes, constraints, and baseline.
2. Build five workload records with confidence-scored dependencies and dispositions.
3. Prove one representative landing-zone path and list gaps as gates or exceptions.
4. Form a wave and rehearse cutover, rollback, data authority, and reconciliation.
5. Define operational, security, recovery, financial, and decommissioning evidence.
6. Compare AWS-first design with Azure and Google Cloud without assuming equivalence.
7. Answer scenarios aloud, score the mock, and revisit only the weakest source areas.
