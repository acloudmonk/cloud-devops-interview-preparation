# Executive and Technical Communication

[← Options and value](options-business-case.md) · [Next: Templates →](templates.md)

Use one decision record but adapt depth.

| Audience | Lead with | Include |
| --- | --- | --- |
| Executive/sponsor | outcome, decision, value, exposure | recommendation, options, cost range, top risks, ask |
| Risk/legal | obligations and residual risk | data flows, controls, evidence, exceptions, owner |
| Finance/procurement | value and commitments | baseline, scenarios, unit economics, contract dependencies |
| Engineering | behavior and constraints | flows, interfaces, failure, migration, acceptance tests |
| Operations/support | service and ownership | SLOs, telemetry, runbooks, escalation, recovery |

## Executive narrative

Situation → consequence → options → recommendation → investment/risk → decision ask.
Put the ask on the first page. Use ranges and confidence. Explain technical risk as
business impact without hiding material detail.

## Technical narrative

Context → requirements → architecture → alternatives → failure/security/operations →
migration → evidence. Walk one user journey and one state change end to end.

Answer the question first, then support it. Say “I do not know; here is how we will
find out” rather than improvising certainty. Close every meeting with decisions,
actions, owners, dates, and the next checkpoint.
