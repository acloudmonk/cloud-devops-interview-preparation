# Consultant Active-Recall Flashcards

[← Rapid fire](rapid-fire.md) · [Next: Mock interview →](../mock-interviews/consultant-discovery.md)

| # | Front | Back |
| ---: | --- | --- |
| 1 | Decision frame | Owner, decision, deadline, outcome, metrics, constraints. |
| 2 | Discovery register | Facts, assumptions, hypotheses, unknowns, risks, decisions. |
| 3 | Evidence hierarchy | Observation/test before records, interviews, assertions. |
| 4 | Outcome | Measurable condition improved for customer/business. |
| 5 | Invariant | Condition that must never be violated. |
| 6 | Quality scenario | Source, stimulus, environment, artifact, response, measure. |
| 7 | Decision owner | Accountable person, not an anonymous committee. |
| 8 | Stakeholder map | Outcome, authority, evidence, incentive, concern, engagement. |
| 9 | Power versus impact | Include affected low-power users and operators. |
| 10 | Workshop contract | Purpose, decision, roles, inputs, rules, outputs. |
| 11 | Silent ideation | Limits anchoring and dominance. |
| 12 | Dissent record | Unresolved view, evidence, impact, owner, escalation. |
| 13 | Conflict reframing | Move positions toward interests, evidence, and criteria. |
| 14 | False consensus | Apparent agreement without resolved or recorded dissent. |
| 15 | Option set | At least two credible choices; consider improve/defer. |
| 16 | Weighted criteria | Stakeholder-agreed decision priorities. |
| 17 | Sensitivity | Whether uncertainty or weights can reverse ranking. |
| 18 | Baseline | Measured current state for comparison. |
| 19 | Counterfactual | Expected state if no change occurs. |
| 20 | Reversible step | Cheap experiment before irreversible commitment. |
| 21 | Exit trigger | Evidence that forces decision review. |
| 22 | Executive story | Situation, consequence, options, recommendation, ask. |
| 23 | Technical story | Context, qualities, flow, failure, operations, migration. |
| 24 | Decision record | Context, choice, rationale, trade-offs, risks, triggers. |
| 25 | Consultant outcome | Better decision, adoption, capability, and measured value. |
